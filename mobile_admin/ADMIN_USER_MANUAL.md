## Introduction

L'application Admin Mobile MaasGa permet aux administrateurs de gérer tous les aspects de l'entreprise MaasGa directement depuis leur appareil mobile. Cette application offre une interface intuitive pour gérer les commandes, les clients, les paiements, et bien plus encore.

### Fonctionnalités principales

- ✅ Dashboard avec KPIs en temps réel
- ✅ Gestion complète des commandes
- ✅ Gestion des rendez-vous et calendrier
- ✅ Gestion des produits et catalogue
- ✅ Gestion des clients et prospects
- ✅ Gestion de la maintenance
- ✅ Création et gestion des devis
- ✅ Suivi des paiements (LigdiCash)
- ✅ Communication avec les clients
- ✅ Service Après-Vente
- ✅ Notifications push
- ✅ Galerie des réalisations
- ✅ Modération des avis
- ✅ Gestion publicitaire
- ✅ Audit et logs d'activité

## Première connexion

### Étape 1: Télécharger l'application

1. Téléchargez l'APK depuis le lien fourni par l'équipe IT
2. Installez l'application sur votre appareil Android
3. Autorisez les permissions demandées (notifications, stockage)

### Étape 2: Authentification

1. Ouvrez l'application
2. Connectez-vous avec votre compte Firebase admin
3. Si c'est votre première connexion, vous serez redirigé vers le Dashboard

### Étape 3: Configuration initiale

1. Vérifiez votre profil dans les **Paramètres**
2. Configurez vos préférences de notification
3. Explorez le Dashboard pour vous familiariser

---

## Dashboard

Le Dashboard est votre point de départ. Il affiche les KPIs clés de l'entreprise en temps réel.

### Indicateurs disponibles

- **Commandes du jour**: Nombre de commandes reçues aujourd'hui
- **Revenus du jour**: Total des revenus générés aujourd'hui
- **Rendez-vous du jour**: Nombre de RDV programmés
- **Maintenance en cours**: Nombre de demandes de maintenance actives
- **Messages non lus**: Nombre de messages clients sans réponse
- **Paiements en attente**: Montant total des paiements en attente

### Actions rapides

- **Voir toutes les commandes**: Accès rapide à la liste des commandes
- **Créer un devis**: Création rapide d'un nouveau devis
- **Voir le calendrier**: Accès au calendrier des RDV
- **Messages**: Accès à la boîte de réception

## Gestion des commandes

### Liste des commandes

1. Accédez à **Commandes** depuis le menu
2. Filtrez par statut (en attente, confirmée, en livraison, livrée, annulée)
3. Recherchez par numéro de commande ou nom de client
4. Tirez vers le bas pour rafraîchir

### Détails d'une commande

1. Tapez sur une commande pour voir les détails
2. Vous pouvez voir:
   - Informations client
   - Articles commandés
   - Statut de la commande
   - Date de création
   - Montant total

### Modifier une commande

1. Ouvrez les détails de la commande
2. Tapez sur **Modifier**
3. Changez le statut ou les informations
4. Sauvegardez les modifications

### Créer une commande

1. Tapez sur le bouton **+** dans l'écran Commandes
2. Sélectionnez le client
3. Ajoutez les produits
4. Validez la commande

## Devis

### Liste des devis

1. Accédez à **Devis** depuis le menu
2. Filtrez par statut:
   - **Brouillon**: Devis non finalisés
   - **Envoyé**: Devis envoyés au client
   - **Accepté**: Devis acceptés par le client
   - **Refusé**: Devis refusés par le client
   - **Expiré**: Devis expirés

### Créer un devis

1. Tapez sur **+** pour créer un nouveau devis
2. Sélectionnez le client
3. Ajoutez les articles:
   - Description
   - Quantité
   - Prix unitaire
4. Le total est calculé automatiquement
5. Sauvegardez comme brouillon

### Envoyer un devis

1. Ouvrez un devis en brouillon
2. Tapez sur **Envoyer**
3. Le statut passe à "Envoyé"
4. Le client recevra une notification

### Convertir en commande

1. Ouvrez un devis accepté
2. Tapez sur **Convertir en commande**
3. Une commande est créée automatiquement
4. Le statut du devis passe à "Converti"

## SAV (Service Après-Vente)

### Tickets SAV

1. Accédez à **SAV** depuis le menu
2. Filtrez par statut:
   - **Ouvert**: Tickets nouvellement créés
   - **En cours**: Tickets en traitement
   - **Résolu**: Tickets résolus
   - **Fermé**: Tickets fermés

### Filtres par priorité

- **Urgent**: Priorité maximale (indicateur rouge)
- **Élevé**: Priorité haute (indicateur orange)
- **Normal**: Priorité normale (indicateur bleu)
- **Faible**: Priorité basse (indicateur vert)

### Créer un ticket

1. Tapez sur **+** pour créer un ticket
2. Sélectionnez le client
3. Décrivez le problème
4. Sélectionnez le type d'équipement
5. Définissez la priorité
6. Sauvegardez

### Assigner un technicien

1. Ouvrez un ticket
2. Tapez sur **Assigner**
3. Sélectionnez un technicien
4. Sauvegardez

### Résoudre un ticket

1. Ouvrez un ticket
2. Tapez sur **Résoudre**
3. Décrivez la solution
4. Le statut passe à "Résolu"

## Notifications

### Campagnes de notifications

1. Accédez à **Notifications** depuis le menu
2. Vous verrez toutes les campagnes de notifications
3. Filtrez par statut:
   - **Brouillon**: Notifications non envoyées
   - **Programmée**: Notifications planifiées
   - **Envoyée**: Notifications envoyées
   - **Annulée**: Notifications annulées

### Créer une notification

1. Tapez sur **+** pour créer une notification
2. Entrez:
   - Titre
   - Corps du message
   - Segment cible (tous, clients actifs, abonnés)
   - Date d'envoi (optionnel pour envoi immédiat)
3. Sauvegardez comme brouillon

### Envoyer une notification

1. Ouvrez une notification en brouillon
2. Tapez sur **Envoyer**
3. La notification est envoyée à tous les utilisateurs du segment cible
4. Le statut passe à "Envoyée"

### Statistiques d'ouverture

Pour chaque notification envoyée, vous pouvez voir:
- Nombre de destinataires
- Nombre d'ouvertures
- Taux d'ouverture (%)

## Support et assistance

### Contacter le support

Si vous rencontrez des problèmes avec l'application:

1. Allez dans **Paramètres** > **Support**
2. Tapez sur **Contacter le support**
3. Décrivez votre problème
4. Envoyez votre demande

### FAQ

**Q: J'ai oublié mon mot de passe.**  
A: Utilisez l'option "Mot de passe oublié" sur l'écran de connexion.

**Q: L'application ne se connecte pas.**  
A: Vérifiez votre connexion internet et réessayez.

**Q: Je ne reçois pas les notifications.**  
A: Vérifiez vos paramètres de notification dans les Paramètres de l'application et de votre appareil.

**Q: Comment mettre à jour l'application?**  
A: Vous recevrez une notification quand une mise à jour est disponible. Tapez sur "Mettre à jour" pour installer.
